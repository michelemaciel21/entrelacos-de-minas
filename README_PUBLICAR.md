# Entrelaços de Minas — site oficial

Site estático e responsivo, pronto para o GitHub Pages.

## Antes de publicar

Abra o arquivo `config.js` e preencha:

- `whatsapp`: use 55 + DDD + número, somente algarismos. Exemplo fictício: `5519999999999`.
- `instagram`: use apenas o nome do perfil, sem `@`. Exemplo: `entrelacosdeminas`.

Todos os botões de contato serão atualizados automaticamente.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `entrelacos-de-minas`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch **main**, pasta **/(root)** e clique em **Save**.
6. Aguarde alguns minutos. O endereço aparecerá na mesma tela.

## Arquivos principais

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: identidade visual, animações e versão para celular.
- `script.js`: menu, efeitos, FAQ e montagem do pedido.
- `config.js`: WhatsApp e Instagram da marca.
- `assets/`: imagens e logo.

Não é necessário instalar nenhum programa para o site funcionar.
